# 随机抽号 · 视觉与动效规范（v2「朱墨」）

> 上一版的问题：M3 只抄了形状（圆角、色块、阴影），没有排版秩序；卡片套卡片，
> 信息被切碎；宋体被当成默认字体直接铺在 12~13px 上，像公文表格；动效只有
> “淡入 + 弹一下”，没有节奏，定格还要等磁盘。
>
> 这一版换一个明确的概念：**一本摊开在讲台上的点名册**。

---

## 一、概念：朱墨

- **纸**：暖白宣纸底（#F7F4ED），表面比底色更亮一档；分区靠 1px 细线与留白，
  不靠卡片、不靠阴影。整页最多两层“纸”，不再出现“卡片里套卡片”。
- **墨**：正文与数字用宋体，靠**字号与字重对比**建立层级，而不是靠彩色块。
  大数字是版面主角，允许占据 40% 的视觉重量。
- **朱砂**：全站只有一个强调色（#C0392B），只给三件事——开始抽号、抽中结果、
  当前选中的页签。其余一律墨色/细线。红色在这里是“点名录”的传统色，不是报错色；
  报错用更暗的 #8E1F16 并配文案，不靠颜色单独传达。

## 二、色彩

| 角色 | 值 | 用途 |
|---|---|---|
| paper | #F7F4ED | 页面底色 |
| surface | #FFFDF8 | 弹窗/浮层纸面 |
| ink | #1B1A17 | 主文字、大数字 |
| ink-2 | #5F5B52 | 次要文字 |
| ink-3 | #A29B8C | 提示、占位 |
| rule | #E2DCCF | 分区细线 |
| rule-soft | #EDE7DB | 行分隔 |
| indigo | #1F4B6E | 结构色（选中、链接、次要按钮） |
| indigo-soft | #DCE7F0 | 选中底、浅色标签 |
| vermilion | #C0392B | 唯一强调：开始、结果、当前页签 |
| vermilion-soft | #F6DFD9 | 结果底、印章底 |
| green | #3F6B50 | 成功提示 |
| amber | #A9761E | 警示（非错误） |

对比度：ink/paper ≥ 14:1；ink-2/paper ≥ 6:1；vermilion/paper ≥ 5:1。

## 三、字阶（全部宋体 SimSun）

| 名称 | 字号 | 字重 | 用途 |
|---|---|---|---|
| display | 176 / 120 / 88 | 600 | 抽号大数字（2 位 / 3 位 / 更宽） |
| h1 | 26 | 400 | 页面标题 |
| h2 | 20 | 400 | 分区标题 |
| h3 | 15 | 600 | 小标题、列头 |
| body | 14.5 | 400 | 正文 |
| small | 12.5 | 400 | 辅助说明 |
| label | 11 | 400 | 拉丁字距标签（letter-spacing 2.4px） |

规则：
- 12.5px 以下不用粗体（宋体伪粗会糊）；
- 大数字用等宽数字特性，避免跳动时宽度抖动；
- 标题不加彩色，靠字号与留白；分区标题下方用 32px 朱砂短线（2px）作标记。

## 四、栅格与间距

- 页边距 32 / 28；主区与右栏 3:2，栏间用 1px 竖线分隔，间距 32。
- 间距阶：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 圆角：输入 8、卡片 12、弹窗 24、按钮全圆角（pill）。
- 阴影：主界面**不用**投影；只有弹窗、批量浮层用一层柔和阴影。

## 五、动效

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 按钮按下 | 90ms | standard | scale 0.97，松开回弹 |
| 页签切换 | 240ms | emphasized | 下划线滑动 + 内容 10px 上移淡入 |
| 抽号滚动 | 55ms/跳 | linear | 数字上下两行滚动（真实位移，不是换字） |
| 停止减速 | 420ms | decelerate | 跳动间隔 55→90→140→200ms，最后落章 |
| 落章 | 620ms | stamp (0.18,1.5,0.4,1) | 数字 1.18→0.97→1，朱砂环扩散，印章旋入 |
| 批量揭晓 | 70ms/张 | stamp | 纸票从 1.3 缩到 1，微旋转 ±2°，朱砂环脉冲 |
| 浮层进入 | 320ms | emphasized | 纸面从下方 24px 升起 + 淡入 |
| 提示条 | 240ms | standard | 上移 12px + 淡入 |

原则：只动 transform / opacity；不做布局动画；不做无意义循环动画（呼吸光晕只在抽号中）。

## 六、响应式断点

| 宽度（逻辑像素） | 布局 |
|---|---|
| ≥ 1120 | 双栏：主区 3 / 右栏 2 |
| 900–1119 | 双栏压缩：右栏只留名单，隐藏名字列 |
| < 900 | 单栏纵向：主区 → 批量 → 右栏，整页可滚动 |
| 高度 < 640 | 大数字降到 120px，隐藏提示行 |

顶栏：< 1180 隐藏新建/重命名/删除文字，收进「班级 ⋯」菜单；< 900 隐藏英文副标题。
弹窗：宽度不超过屏幕 88%，高度不超过屏幕 84%，超出时正文可滚动。
批量浮层：宽高都按父窗口 90% 上限计算，卡片网格按可用宽度自动 3~5 列。

## 七、反模式（明确不做）

- 不做「卡片里再放卡片」；主界面零投影。
- 不用荧光色、渐变紫蓝、玻璃拟态。
- 不在 12px 以下使用粗体宋体。
- 不用 emoji 当图标；图标统一 1.5px 线宽、圆头。
- 不做循环呼吸/漂浮装饰；除抽号中，页面保持静止。
- 不用系统 QMessageBox / QFileDialog。
